# aprende → pawsport redirect

Publish this folder as the repository `pchattani/aprende` (GitHub Pages from the main branch, root) after the
main repository has been renamed to `pawsport`. Every old URL under `/aprende/` forwards to `/pawsport/`, and the
`sw.js` files replace the old service workers (the hub's and each course's) so installed apps stop serving stale copies.
